# 诗词 App poetry-app

> 跨平台诗词学习应用，面向中东市场的中国诗词文化入门工具。

## 基本信息

| 项目 | 内容 |
|------|------|
| **技术栈** | Expo · React Native · TypeScript · SQLite |
| **目标市场** | 沙特、阿联酋、卡塔尔 |
| **状态** | ⚠️ 80% — 无 GitHub Remote |

## 产品定位

为中东富裕国家的商务人士和文化爱好者提供的高端轻量级诗词文化学习 APP。

**核心创新**：
- 🌍 **跨文化历史对比** — 中国朝代 ↔ 中东历史对应
- 🤖 **智能推荐** — 基于节日、星期的动态推荐
- 📖 **阿拉伯语为主** — 界面完全阿拉伯语化 + RTL 支持

## 核心功能

- 中阿对照诗词阅读
- 精美水墨风格卡片分享
- 离线使用（本地 SQLite 数据库）
- AI 翻译质量评估与优化
- VIP 会员体系

## 数据管道

项目包含大量数据脚本（backfill、翻译评估、纠错等），用于：
- 从古诗数据源批量导入诗词
- AI 翻译（中→阿）+ 质量评估
- 多轮翻译优化（backtranslate 验证）

## 技术方案

| 类别 | 方案 |
|------|------|
| 框架 | React Native + Expo |
| 状态管理 | Zustand |
| 本地存储 | AsyncStorage + SQLite |
| 后端 | Supabase（未来扩展） |
| UI | React Native Paper (Material Design 3) |
