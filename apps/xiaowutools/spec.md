# 小工具箱 (xiaowutools-v2) - 项目规范

## 1. 项目概述

- **项目名称**: 小工具箱
- **类型**: 工具类网站
- **核心功能**: 短视频下载、图片转换、微信截图生成
- **目标用户**: 普通用户、自媒体创作者

## 2. UI/UX 规范

### 布局结构

- **Header**: 固定顶部，包含 Logo 和导航
- **Hero**: 首页工具卡片展示
- **Content**: 工具详情页
- **Footer**: 版权信息和链接

### 响应式断点

- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

### 视觉风格

- **主色调**: 渐变紫粉 (from-purple-600 to-pink-600)
- **字体**: Inter / system-ui
- **圆角**: rounded-xl (12px)
- **阴影**: shadow-lg

## 3. 功能规范

### 3.1 抖音/TikTok 下载器

**功能**:
- 输入抖音/TikTok 链接
- 解析无水印视频
- 支持视频下载
- 支持 MP3 提取

**UI**:
- 输入框 + 解析按钮
- 视频预览
- 下载按钮

### 3.2 图片转 ICO

**功能**:
- 上传图片
- 选择尺寸 (16, 32, 48, 64, 128, 256)
- 转换为 ICO 格式下载

**UI**:
- 拖拽上传区域
- 尺寸选择器
- 预览 + 下载按钮

### 3.3 微信聊天截图

**功能**:
- 自定义头像
- 添加对话内容
- 支持文字、图片、红包、转账
- 生成截图

**UI**:
- 左侧设置面板
- 右侧手机预览
- 实时更新

## 4. 技术栈

- **前端**: Next.js 14 + React + TypeScript
- **UI**: Tailwind CSS + shadcn/ui
- **后端**: Next.js API Routes
- **图片处理**: Sharp (ICO 转换)
