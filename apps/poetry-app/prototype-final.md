## 📋 产品概述

### 产品定位
> 为中东富裕国家（沙特、阿联酋、卡塔尔）的商务人士和文化爱好者提供的高端轻量级诗词文化学习 APP，通过精美的水墨风格设计和社交分享功能，让零基础用户在每天 5-10 分钟的碎片时间里，轻松理解中国诗词文化。

### 核心价值
1. **最简单的入门工具** - 零基础也能看懂
2. **最精美的文化体验** - 中国风水墨设计 + 深度解读
3. **最适合社交分享** - 精美卡片 + 一键分享

### 核心创新
- **跨文化历史对比**：中国朝代 ↔ 中东历史对应
- **智能推荐**：基于节日、星期的动态推荐
- **阿拉伯语为主**：界面完全阿拉伯语化 + RTL 支持

## 🎯 产品功能

### 信息架构

**页面结构**:
```
底部导航栏: [首页] [浏览] [我的]
+ 诗词详情页（点击进入）
```

**分类维度**（5个）:
1. 按主题（爱国、家国、亲情、励志、自然）
2. 按诗人（李白、杜甫、王维...）
3. 按朝代（唐、宋、明、清）
4. 按情感（快乐、悲伤、思念、愤怒、平静）
5. 按节日（春节、中秋、端午、清明）

## 📚 内容策略

### 数据来源
- chinese-poetry/chinese-poetry 仓库（33万首）
- 全部数据，按需翻译

### 诗词数量
- **1周MVP**: 100首精选（有阿拉伯语翻译）
- **上线后**: 每天自动翻译 500-1000 首

### 筛选标准
1. 知名度（最著名的诗）
2. 诗人代表作
3. 朝代平衡

### 翻译策略
- **阿拉伯语翻译**: AI翻译（GPT-4）
- **文化解读**: AI生成（200-300字）
- **成本**: $6-15（100首）

### 内容更新
- 定时任务自动翻译
- 每天 500-1000 首
- 存入数据库
- APP 通过 API 读取

## 🛠️ 技术方案

### 产品形态
- **跨平台移动应用**
  - Android APK（主要）
  - iOS APP
  - 鸿蒙系统兼容（潜在）
- 阿拉伯语界面
- 手机优先设计不做 PWA
- ❌ 不做 APK

### 技术栈
- **前端**: Next.js 14 + React + TypeScript
- **样式**: Tailwind CSS + shadcn/ui
- **数据库**: Supabase（PostgreSQL）
- **认证**: Supabase Auth（Google OAuth）
- **支付**: Stripe
- **部署**: Vercel
- **AI翻译**: GPT-4 API

### 多语言支持
- **界面语言**: 阿拉伯语（不支持切换）
- **RTL支持**: 完整的从右到左布局
- **诗词**: 中文+阿拉伯语对照

### 性能要求
- 首页加载: < 2秒
- 分页: 每页 10首
- 搜索: < 1秒
