## 二、功能测试

### F-01：DICOM 多帧读取

| 项目 | 内容 |
|------|------|
| **前置** | 准备标准多帧 DICOM 文件（≥50 帧） |
| **步骤** | 1. `SequenceReader("sample.dcm")` 2. 检查 `frame_count` 3. 遍历读取每一帧 |
| **预期** | frame_count 与文件实际帧数一致；每帧为灰度 ndarray，尺寸一致，无 NaN |

### F-02：MP4 视频读取

| 项目 | 内容 |
|------|------|
| **前置** | 准备 MP4 视频文件（30fps, ≥100 帧） |
| **步骤** | 1. `SequenceReader("sample.mp4")` 2. 检查 `fps` 3. 读取第 0、50、末帧 |
| **预期** | fps 与视频实际帧率一致；帧读取无报错；末帧索引正确 |

### F-03：DICOM 时间轴构建

| 项目 | 内容 |
|------|------|
| **前置** | DICOM 文件含 Frame Time Vector (0018,1065) |
| **步骤** | 1. 读取 `get_time_axis()` 2. 验证首帧 = 0，每帧间隔 > 0 |
| **预期** | 时间轴为严格递增数组；总时长 ≈ frame_count × 帧间隔 |

### F-04：MP4 时间轴降级

| 项目 | 内容 |
|------|------|
| **前置** | MP4 文件无 DICOM 元信息 |
| **步骤** | 1. 读取 `get_time_axis()` 2. 验证按 fps 换算 |
| **预期** | time_ms[i] = i × 1000 / fps；无异常 |

### F-05：Pixel Spacing 读取

| 项目 | 内容 |
|------|------|
| **前置** | DICOM 含 Pixel Spacing (0028,0030) = 0.2 mm/px |
| **步骤** | 1. 读取 `get_pixel_spacing()` |
| **预期** | 返回 0.2；distance_mm = distance_px × 0.2 |

### F-06：首帧人工初始化

| 项目 | 内容 |
|------|------|
| **前置** | 首帧含两个清晰可见 marker |
| **步骤** | 1. 传入两个点选坐标 2. 检查 MarkerState |
| **预期** | A/B 各有模板、搜索窗、初始位置；模板尺寸 = 2×template_radius+1 |

### F-07：模板匹配跟踪

| 项目 | 内容 |
|------|------|
| **前置** | 标准 DICOM 样本，marker 全程可见 |
| **步骤** | 1. 首帧初始化 2. 逐帧模板匹配 3. 检查每帧输出 |
| **预期** | 每帧输出 center + score；score > 0.5 的帧占比 > 90% |

### F-08：光流预测跟踪

| 项目 | 内容 |
|------|------|
| **前置** | 连续帧序列 |
| **步骤** | 1. 对 A/B 分别用 calcOpticalFlowPyrLK 2. 检查 status |
| **预期** | status 均为 1；预测位置与模板匹配位置偏差 < 5px |

### F-09：双路融合

| 项目 | 内容 |
|------|------|
| **前置** | 标准序列 |
| **步骤** | 1. 光流预测 + 模板匹配 2. 检查融合结果 |
| **预期** | 一致时取模板匹配结果；不一致时标记低置信度 |

### F-10：距离曲线生成

| 项目 | 内容 |
|------|------|
| **前置** | 完整跟踪结果（100 帧） |
| **步骤** | 1. `compute_metrics(results)` 2. 检查输出 |
| **预期** | raw_distances 长度 = 100；d_max > d_min > 0；d_pp = d_max - d_min |

### F-11：CSV 导出

| 项目 | 内容 |
|------|------|
| **前置** | 完整跟踪结果 |
| **步骤** | 1. `export_csv(results, time_axis, "output.csv")` 2. 用 pandas 读取验证 |
| **预期** | 列数 = 10；行数 = frame_count；无空值（低置信度帧 score 列仍有效值） |

### F-12：曲线图导出

| 项目 | 内容 |
|------|------|
| **前置** | DistanceMetrics 已计算 |
| **步骤** | 1. `export_curve_plot(metrics, "output/")` 2. 检查文件 |
| **预期** | 生成 PNG + PDF；图片包含原始曲线和平滑曲线；标注 d_max/d_min |

## 三、质量指标测试

### Q-01：轨迹完整率 ≥ 95%

| 项目 | 内容 |
|------|------|
| **前置** | 标准 DICOM 样本（200 帧，marker 全程可见） |
| **步骤** | 1. 运行完整 pipeline 2. 计算 valid_frames / total_frames |
| **预期** | completeness_rate ≥ 0.95 |

### Q-02：低置信度帧比例 ≤ 10%

| 项目 | 内容 |
|------|------|
| **前置** | 同 Q-01 样本 |
| **步骤** | 1. 统计 score < 0.5 的帧数 |
| **预期** | low_confidence_rate ≤ 0.10 |

### Q-03：串 ID 率 < 1%

| 项目 | 内容 |
|------|------|
| **前置** | 标准样本，A/B 间距 > 50px |
| **步骤** | 1. 逐帧检查 A/B 相对位置关系 2. 检测 swap_events |
| **预期** | swap_events 数量 = 0（200 帧内不应发生串 ID） |

### Q-04：曲线重复性 CV < 2%

| 项目 | 内容 |
|------|------|
| **前置** | 同一标准样本 |
| **步骤** | 1. 运行 pipeline 3 次 2. 计算 d_mean 的变异系数 |
| **预期** | CV = std(d_mean_1, d_mean_2, d_mean_3) / mean(...) < 0.02 |

### Q-05：单帧处理耗时 < 50ms

| 项目 | 内容 |
|------|------|
| **前置** | 标准帧 (512×512) |
| **步骤** | 1. 计时 track_frame 单帧执行 |
| **预期** | 平均耗时 < 50ms（不含 IO） |

### Q-06：200 帧序列总耗时 < 30s

| 项目 | 内容 |
|------|------|
| **前置** | 标准 DICOM（200 帧） |
| **步骤** | 1. 计时完整 pipeline（含导出） |
| **预期** | 总耗时 < 30s |

## 四、异常处理测试

### E-01：DICOM 文件损坏

| 项目 | 内容 |
|------|------|
| **步骤** | 传入损坏的 .dcm 文件 |
| **预期** | 抛出明确异常（非段错误），包含文件路径和错误原因 |

### E-02：空帧序列（0 帧）

| 项目 | 内容 |
|------|------|
| **步骤** | 传入帧数为 0 的输入 |
| **预期** | 优雅报错："输入序列帧数为 0，无法处理" |

### E-03：首帧点选越界

| 项目 | 内容 |
|------|------|
| **步骤** | 点选坐标超出图像范围（如 x=-5 或 x=width+10） |
| **预期** | 提示重新点选，不产生越界访问 |

### E-04：全程跟丢

| 项目 | 内容 |
|------|------|
| **前置** | 模拟序列，marker 在第 5 帧后完全消失 |
| **步骤** | 运行 pipeline |
| **预期** | 连续 10 帧失追后中断；输出已跟踪段结果 + 失败报告 |

### E-05：Pixel Spacing 缺失

| 项目 | 内容 |
|------|------|
| **步骤** | DICOM 无 (0028,0030) tag |
| **预期** | distance_mm 相关字段为 None；px 结果正常输出 |

### E-06：Frame Time Vector 缺失

| 项目 | 内容 |
|------|------|
| **步骤** | DICOM 无 (0018,1065) tag |
| **预期** | 降级为 fps 或 frame index 时间轴；报告中标注降级原因 |

### E-07：MP4 严重压缩

| 项目 | 内容 |
|------|------|
| **前置** | 低码率 MP4（marker 模糊） |
| **步骤** | 运行 pipeline |
| **预期** | 大量帧被标记低置信度；曲线能输出但附质量警告 |

### E-08：Marker 短时遮挡

| 项目 | 内容 |
|------|------|
| **前置** | 模拟序列，marker B 在第 30-35 帧被遮挡 |
| **步骤** | 运行 pipeline |
| **预期** | 30-35 帧标记低置信度；36 帧后恢复跟踪（一级恢复成功）；曲线对应段标注异常 |

## 五、边界条件测试

### B-01：最小帧数（2 帧）

| 项目 | 内容 |
|------|------|
| **步骤** | 传入仅含 2 帧的序列 |
| **预期** | 正常输出 2 个距离值；统计摘要可用（d_max = d_min = d_pp = 唯一值） |

### B-02：大帧数（1000+ 帧）

| 项目 | 内容 |
|------|------|
| **步骤** | 传入 1000 帧序列 |
| **预期** | 内存 < 2GB；无 OOM；处理完成无报错 |

### B-03：Marker 最小尺寸（3×3 px）

| 项目 | 内容 |
|------|------|
| **步骤** | marker 仅占 3×3 像素 |
| **预期** | 跟踪可能不稳定，但系统不崩溃；低置信度帧比例升高 |

### B-04：两 Marker 距离极近（< 10px）

| 项目 | 内容 |
|------|------|
| **步骤** | A/B 中心间距 < 10px |
| **预期** | 串 ID 检测频繁触发；标记为高 swap 风险 |

### B-05：Marker 在图像边缘

| 项目 | 内容 |
|------|------|
| **步骤** | marker 中心距边缘 < template_radius |
| **预期** | 模板提取做 padding 或裁剪；跟踪继续但可能降低精度 |

### B-06：全黑/全白帧

| 项目 | 内容 |
|------|------|
| **步骤** | 序列中间插入全黑帧 |
| **预期** | 该帧标记低置信度（score ≈ 0）；前后帧跟踪不受影响 |
